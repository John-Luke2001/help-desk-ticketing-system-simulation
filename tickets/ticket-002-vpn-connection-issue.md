# Ticket 002: VPN Connection Issue

## Ticket ID

TICKET-002

## Issue Summary

User is unable to connect to the company VPN.

## User Impact

The user cannot access internal company resources while working remotely.

## Priority

Medium

## Category

Network / VPN Access

## User Reported Issue

The user reported that they were unable to connect to the company VPN from their home network. They stated that the VPN client showed a connection error and would not allow access to internal resources.

## Troubleshooting Steps

1. Verified that the user had an active internet connection.
2. Confirmed that the user was using the correct VPN client.
3. Asked the user to restart the VPN application.
4. Confirmed that the username and password were entered correctly.
5. Checked whether multi-factor authentication was being completed successfully.
6. Asked the user to restart their computer and try connecting again.
7. Confirmed that the VPN connection was restored.

## Resolution

The VPN client connected successfully after the user restarted the VPN application and completed multi-factor authentication.

## Escalation Needed

No

## Escalation Notes

No escalation was required because the issue was resolved at Tier 1.

## Customer Communication

Informed the user that the VPN connection was restored and reminded them to fully complete the multi-factor authentication prompt when connecting remotely.
