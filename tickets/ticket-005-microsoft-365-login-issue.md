# Ticket 005: Microsoft 365 Login Issue

## Ticket ID

TICKET-005

## Issue Summary

User is unable to sign in to Microsoft 365.

## User Impact

The user cannot access Outlook, Teams, OneDrive, or other Microsoft 365 services needed for daily work.

## Priority

Medium

## Category

Microsoft 365 / Account Access

## User Reported Issue

The user reported that they were unable to sign in to Microsoft 365 applications. They stated that Outlook and Teams kept asking for a password and would not complete the sign-in process.

## Troubleshooting Steps

1. Verified the user's identity according to company policy.
2. Confirmed that the user was entering the correct username and password.
3. Checked whether the account was locked or disabled.
4. Asked the user to complete the multi-factor authentication prompt.
5. Had the user close and reopen Microsoft 365 applications.
6. Recommended clearing saved credentials if the issue continued.
7. Confirmed that the user was able to sign in successfully.

## Resolution

The user completed multi-factor authentication and was able to access Microsoft 365 applications successfully.

## Escalation Needed

No

## Escalation Notes

No escalation was required because the issue was resolved at Tier 1.

## Customer Communication

Informed the user that their Microsoft 365 access was restored and reminded them to complete the MFA prompt when signing in.
