# Ticket 003: Printer Not Working

## Ticket ID

TICKET-003

## Issue Summary

User is unable to print to the office printer.

## User Impact

The user cannot print required documents for daily work tasks.

## Priority

Low

## Category

Hardware / Printer Support

## User Reported Issue

The user reported that documents were not printing from their workstation. The printer appeared online, but the print job remained stuck in the queue.

## Troubleshooting Steps

1. Verified that the printer was powered on and connected to the network.
2. Confirmed that other users were able to print to the same printer.
3. Checked the user's default printer settings.
4. Cleared the stuck print job from the print queue.
5. Restarted the printer spooler service.
6. Sent a test page to confirm printing was working.

## Resolution

The stuck print job was cleared, the print spooler service was restarted, and the user was able to print successfully.

## Escalation Needed

No

## Escalation Notes

No escalation was required because the issue was resolved at Tier 1.

## Customer Communication

Informed the user that the print queue was cleared and confirmed that a test page printed successfully.
