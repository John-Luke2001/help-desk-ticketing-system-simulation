# Ticket 004: Slow Computer Performance

## Ticket ID

TICKET-004

## Issue Summary

User reports that their computer is running slowly.

## User Impact

The user is experiencing delays when opening applications and completing daily work tasks.

## Priority

Medium

## Category

Windows Support / Performance

## User Reported Issue

The user reported that their workstation had become slow throughout the day. Applications were taking longer than usual to open, and the system felt unresponsive during normal work tasks.

## Troubleshooting Steps

1. Asked the user when the issue started and whether any recent changes were made.
2. Confirmed the computer had been restarted recently.
3. Opened Task Manager to review CPU, memory, and disk usage.
4. Checked for unnecessary applications running in the background.
5. Reviewed startup applications that could affect performance.
6. Confirmed available storage space on the device.
7. Recommended closing unused applications and restarting the workstation.
8. Verified with the user that performance improved after restarting and closing unnecessary background applications.

## Resolution

The workstation performance improved after closing unnecessary background applications and restarting the computer.

## Escalation Needed

No

## Escalation Notes

No escalation was required because the issue was resolved at Tier 1.

## Customer Communication

Informed the user that several background applications were using system resources and recommended restarting the computer regularly to help maintain performance.
