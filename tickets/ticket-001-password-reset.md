# Ticket 001: Password Reset Request

## Ticket ID
TICKET-001

## Issue Summary
User is unable to log in and needs a password reset.

## User Impact
The user cannot access their workstation or company resources.

## Priority
Medium

## Category
Account Access / Password Reset

## User Reported Issue
The user reported that they were unable to log in after several failed password attempts.

## Troubleshooting Steps
1. Verified the user's identity according to company policy.
2. Checked whether the account was locked, disabled, or showing suspicious activity.
3. Reset the user's password.
4. Required the user to create a new password at next sign-in.
5. Confirmed that the user was able to log in successfully.

## Resolution
The password was reset successfully, and the user regained access to their workstation.

## Escalation Needed
No

## Escalation Notes
No escalation was required because the issue was resolved at Tier 1.

## Customer Communication
Informed the user that their password was reset and reminded them to create a strong password that meets company requirements.

## Skills Demonstrated
- Account access support
- User verification
- Password reset workflow
- Security awareness
- Ticket documentation
